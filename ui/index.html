Rappel de pause

Émulation Xbox

Ta DualSense devient une manette Xbox 360 pour tous les jeux PC, avec les réglages de ton profil.

Utilise HidHide (Nefarius). Sans le mode administrateur, Windows demande une autorisation à chaque masquage. En quittant MeikiCtrl, la DualSense redevient visible.

À savoir

Steam : si Steam Input est activé pour ta DualSense, désactive-le pour ce jeu, sinon il y aura un doublon.

MeikiCtrl n'a ni macros ni turbo. Sur COD, Ricochet peut sanctionner ce genre d'outils en partie classée.
